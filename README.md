# 南明舆图 · Nanming Atlas

> 明末—南明(约 1580–1664)历史时空可视化:地图/地球上的**疆界变迁、军队行进路线、大事件时间轴、人物知识图谱**,四层联动。

一句话:GitHub 上现有的明朝历史可视化开源项目**全部止步于 1644**。本仓库专补 1644–1664(南明)这段空白,并把 1580 年以来的明末数据串成完整的时空叙事。

- 时间范围:1582(万历十年,张居正去世)→ 1664(茅麓山之战,大陆抗清终点),郑氏台湾可延伸至 1683
- 性质:个人非商用项目

## 为什么要做(2026-10 调研结论)

对 GitHub 全量检索后的核心判断:方向可行、碎片齐全,但**没人做出完整版**。

| 现有项目 | 它做了什么 | 止步于哪里 |
|---|---|---|
| [CochraneK/ming](https://github.com/CochraneK/ming) | 《明朝那些事儿》全量结构化:1231 人物、563 地点(533 带坐标)、1106 事件、2324 关系 | 事件止于 1645(仅 1 条);无疆界、无路线 |
| [Jokeyou/MingGraph](https://github.com/Jokeyou/MingGraph) | D3 力导向图谱 + 时间线(716 节点) | 皇帝表止于崇祯;明末窗口内有效数据极稀疏 |
| [HyperDeem/MingDynasty](https://github.com/HyperDeem/MingDynasty) | 疆域快照 + 时间轴联动 | 6 个快照止于 1644;全仓库无"南明"二字 |

**1644–1662 的南明(弘光/隆武/绍武/永历/郑氏)是所有现成项目的共同空白,也是本项目的核心差异化。**

## 产品形态(四层联动)

1. **疆界层**:明、后金/清、大顺、大西、蒙古诸部、朝鲜、日本、南明诸政权的控制区随时间变化(政权多边形快照 + 过渡动画)
2. **行军层**:萨尔浒(1619)、己巳之变(1629)、松锦(1640–42)、李自成东进(1644)、清军入关(1644)、李定国两蹶名王(1652)、郑成功北伐(1659)等,带时间戳的轨迹动画
3. **事件层**:可拖动/播放的时间轴,事件与地图点位、人物卡片联动
4. **人物层**:知识图谱(君臣/敌对/姻亲/荐举/同盟),与地图双向联动

详细调研见 [docs/data-survey.md](docs/data-survey.md)。概括:

- **CBDB(哈佛)**:单机版发布时点前的数据为 CC BY-NC-SA 4.0。派生数据需署名,不提供公开批量接口。
- **MIT 可直接用**:[ming-history-timeline](https://github.com/RipWheeler-max/ming-history-timeline)(53 事件 + 66 人物 + 关系,本项目的骨架数据)、MingGraph 的图谱组件(保留署名)。
- **无 License = 默认保留所有权利**:ming、percent4 三元组等只本地参考,不复制入库。

## 路线图

- **M1 — 事件时间轴 + 地图点位**(✅ 2026-10 已落地,见下"当前进度")
- **M2 — 疆界快照**(✅ 2026-10 已落地):自绘政权面 10 断面(万历十年→茅麓山)随时间轴 cross-fade;CHGIS 政区打底走本地管线,可选启用
- **M3 — 行军动画**(✅ 2026-10 已落地):自建 4 条 MVP 路线(萨尔浒 / 己巳之变 / 李自成东进 / 清军入关),maplibre 原生轨迹切片动画(未引 deck.gl),与时间轴播放联动
- **M4 — 人物图谱**(✅ 2026-10 已落地):53 人 103 条自学史标注关系,手写力导向图谱(零新依赖),与事件卡/地图双向联动;CBDB 批量抽取留作后续增量
- **M5 — 地球化**(✅ 2026-10 已落地):右上"地球"一键切换三维视角——零依赖 Canvas 正交投影球,复用全部数据与状态;three-globe 留作未来贴纹理的升级路径

## 当前进度(M1–M5 全部落地)

- **M1 数据**:`data/raw/nanming-events.json` 自建 97 条事件(1581–1664,含经纬度、日期精度、阵营、置信度与出处),`data/raw/nanming-people.json` 53 人索引;`npm run data:build` 跑不变量校验并产出 `data/events.json` / `data/people.json`。日期把握不足的条目显式标 `confidence: medium/approx`,不造假精确;坐标为约位的条目带 `coordNote`。
- **M2 疆界快照**:`data/raw/regime-snapshots.json` 自绘 10 个政权面断面——万历十年(1580–1615)/ 后金天命 / 己巳之变 / 甲申鼎革 / 弘光溃 / 隆武·绍武 / 永历·两蹶名王 / 郑成功北伐 / 永历殉国 / 茅麓山落日(至 1666),共 45 个政体面(明、后金清、大顺、大西、南明、郑氏、蒙古诸部、和硕特、朝鲜、日本、荷兰东印度公司),每个快照注明史源与"示意精度"。门禁保证区间无缝铺满 1580–1666、环闭合、政体枚举合法。前端随时间轴年变化自动切换断面(左下快照条可点选、可开关疆界层),切换用 A/B 双层 rAF 缓动 cross-fade。
- **M3 行军动画**:`data/raw/campaign-routes.json` 自建 4 条 MVP 路线共 11 个行军纵队 42 个带时间戳的航点(萨尔浒之战含明四路与后金内线机动、己巳之变含皇太极入塞与袁崇焕入卫、李自成东进含南北两路夹击、清军入关含多尔衮兼程与吴三桂乞师),关键日为公历、农历节点用月份精度。实现走 maplibre 原生等价方案(未引 deck.gl):全程淡虚线铺底 + "已行进"亮线按播放头切片内插 + 白色头部动点,空格播放/拖拽时间轴即动画;左上 RouteBar 可整体开关或单路线显隐,悬停显示纵队名。
- **M4 人物图谱**:`data/raw/person-relations.json` 为 53 人自学史标注的 103 条关系(君臣/父子/兄弟/叔侄/师生/同僚/荐举/同盟/反目/敌对,每条带史注与置信度),门禁保证两端人物存在、无自环、无重复。图谱走手写力导向(零新依赖):点阵斥力 + 边弹簧 + 向心,节点按阵营着色、按关系度定大小,支持拖拽、滚轮缩放、空白平移;右上"人物图谱"开关打开面板,点人物节点看生平、关系网与相关事件(点击事件即跳事件卡),事件卡里的人物 chips 反向一键打开图谱并聚焦。CBDB(哈佛)批量抽取留作后续增量(许可为 CC BY-NC-SA,署名后可用)。
- **M5 地球化**:右上"地球"开关切换三维视角——手写 Canvas 正交投影球(零新依赖,~10KB 独立懒加载 chunk),拖拽旋转、滚轮缩放、静置 4 秒自动缓旋;与 2D 共享同一份数据与状态:疆界断面随年份切换、行军亮线随播放头推进、事件点按窗口明暗并可点选(选中即转球至事件上空,联动事件卡)。取舍:实测 three-globe 观感依赖一张全球纹理(外部资源),而自研球在无纹理时观感等同,故不引入 ~600KB 的 three 依赖;`three-globe` 留作未来需要贴图/大气层效果的升级路径(依赖已验证可安装)。
- **CHGIS 政区打底(可选)**:CHGIS V6 为学术许可(可用、不可再分发),图层不入库——把本地 GeoJSON 放进 `data/chgis/`(目录与产物均已 gitignore),跑 `npm run data:chgis` 简化成 `public/chgis.local.json`,前端运行时加载并按断面年份过滤时序政区、显示许可声明;文件不存在时自动跳过,不影响其他功能。
- **前端**:`pnpm dev` 后即为四层联动的第一、二层——MapLibre 深色底图 + 政权面快照 + 按阵营着色的事件点(点大√重要度),底部时间轴(万历—康熙年号带、南明高亮、拖拽/空格播放/←→步进、±N 年视野窗),点击点位或时间轴圆点弹出事件卡(摘要、结果、人物、出处,‹›可按时间前后翻)。
- **底图**:Esri World Dark Gray(免费、无 key、暗色)。原拟用的 Carto 免费瓦片 2026 年起要求 API key(瓦片直接印 "API KEY REQUIRED"),弃用。
- **两个 maplibre 坑(已绕过,改样式前先读)**:① 含 `zoom` 的 interpolate 表达式只能作 paint 属性顶层,不能嵌进 `+` 等算术表达式;② 免费栅格 CDN 被限流重试时,`load`/`isStyleLoaded()` 可能长期不就绪——事件源与图层因此直接写进初始 style,数据更新用轮询 `getSource` 而非事件门控(见 `src/components/MapView.tsx` 注释)。

## 本地运行

```bash
pnpm install
npm run data:build   # 校验并产出 data/*.json(事件/人物/疆界快照)
npm run data:chgis   # 可选:本地 CHGIS → public/chgis.local.json(政区打底)
pnpm dev             # http://localhost:3000
```

底图瓦片首次绘制较慢(免费源限流),约 10–20 秒后渐显;事件点与疆界面不受影响。

## 技术栈(拟)
