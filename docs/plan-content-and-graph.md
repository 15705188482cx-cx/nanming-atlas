## ④ Neo4j 人物关系图谱

- 定位:WeKnora=文献检索,PG=事实底座,Neo4j=关系查询引擎(多跳/最短关系链/N度共现)。
- 部署:docker-compose 增 `neo4j:5-community`(约 600MB 镜像 + 1GB 内存,已报备获批),与 atlas-pg 同网络,
  数据卷持久化;PG 保持唯一事实源,Neo4j 只做查询层。
- 前置:392 人**别名去重**(郝摇旗/郝永忠等,用 pub.person_aliases),避免幽灵节点。
- 导入:PG 导出 people/relations CSV → neo4j-admin import;查询 API 用 neo4j-driver 挂 Next.js route;
  前端现有手写力导向图升级数据源:两人最短关系链、按阵营/关系类型过滤、事件卡带出同事件人物。
