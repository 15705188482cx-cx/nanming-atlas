### S3 阵营颜色体系(半天,必备件③)
- **一处定义、处处使用**:`pub.factions` 表(color 字段)为唯一权威色板;
- 统一现有散落的配色:明/后金清/大顺/大西/南明/郑氏 六大阵营 + 各小政权色;
- 输出到导出 JSON,地图疆界面、Cesium 球面、人物图谱节点、事件卡徽标全部读同一色板。

### S4 疆域边界矢量图 MVP(1 天,必备件②)
- 底稿:现有 10 断面 45 个政体面(自绘 GeoJSON,带阵营归属)直接复用;
- 增量:按顾书补 2–3 个试点断面(如 1648 金李反正、1653 孙李内讧),政体面标注置信度与出处;
- CHGIS 时序政区打底暂不进 MVP(阶段二),MVP 用自绘面保证"能看"。

### S5 Cesium 三维地球(1 天,必备件②③的舞台)
- 替换自研 Canvas 球:`cesium@1.140` 懒加载(node_modules +80MB,首载 140KB 不变);
- 球上渲染:Esri 深灰底图 + **疆界面(阵营色填充+边界线)** + 行军路线(已行进亮线动画)+ 事件点(按时间窗口明暗、点选);
- 交互:拖拽/缩放/静置自动缓旋;点事件转镜头 flyTo 联动事件卡;2D(maplibre)/3D(Cesium) 一键切换,共享同一份数据与状态。

### S6 人物知识图谱 MVP(半天,必备件①)
- PG 数据:people/relations/event_people 由试点数据填充;
- 前端:现有 PersonGraph 组件改吃新数据,节点=阵营色(同一色板),点人看生平+关系网+相关事件;
- 每条关系可看出处引文(点击弹出处段落)。

### S7 联调与验收(2 小时)
- PG → `data/*.json` 导出(字段对齐现有 schema)→ build-data.mjs 门禁 → build + next start + curl;
- **S8 验收清单(你逐项判定)**:
  1. 三维地球:势力疆域按阵营色渲染、随时间轴切换断面、可拖转缩放;
  2. 疆域矢量:边界清晰、政权归属明确、颜色与图谱/事件卡一致;
  3. 人物图谱:可拖拽缩放、点人看关系网与出处;
  4. 数据溯源:任点一条事件/人物/关系,能看出自《南明史》哪章哪段;
  5. 结论:方案成立与否 → 成立即进入阶段二。
